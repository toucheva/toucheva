# ไร่ดีมีสุข Merge — ต้นแบบเล่นได้

เกมแนว **รวมร่าง (merge)** ธีมฟาร์มผัก ได้แรงบันดาลใจจาก Tropical Merge

> เปลี่ยนแนวมาจากเกมฟาร์มซิมเดิม เอกสารออกแบบฉบับฟาร์มยังอยู่ที่
> [`../docs/GAME_DESIGN.md`](../docs/GAME_DESIGN.md) และโค้ดเดิมยังอยู่ในประวัติ git
> ส่วนหลักการที่ยกมาใช้ต่อดูที่ [`../docs/MERGE_DESIGN.md`](../docs/MERGE_DESIGN.md)

## วิธีเอาไปเล่น

**ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร**

```bash
npm install
npm run bundle     # ได้ dist-single/rai-dee.html ~51 kB
```

ดับเบิลคลิกไฟล์นั้นได้เลย เปิดออฟไลน์ได้ เซฟลง localStorage ของเบราว์เซอร์

**แบบพัฒนาต่อ**

```bash
npm run dev        # เซิร์ฟเวอร์พัฒนา
npm run build      # ตรวจชนิดข้อมูล + สร้างไฟล์แจกจ่าย
```

## วิธีเล่น

| ทำอะไร | ได้อะไร |
|---|---|
| **แตะแปลงผัก / กองไม้** | ปล่อยของออกมาหนึ่งชิ้น มีจำนวนครั้งจำกัด แล้วชาร์จเองตามเวลา |
| **ลากของชนิดเดียวกันมาต่อกันครบ 3 ชิ้น** | รวมเป็นขั้นถัดไปของสาย |
| **ต่อกันครบ 5 ชิ้น** | รวมแล้วได้ของแถมอีกหนึ่งชิ้น |
| **แตะวัชพืช / ก้อนหิน / ตอไม้** | ถางด้วยพลังงาน ได้พื้นที่คืนพร้อมของที่ร่วง |
| **แตะเหรียญ** | เก็บเป็นเงิน ยิ่งรวมขั้นสูงยิ่งคุ้ม |
| **ส่งคำสั่งซื้อ** | ได้เหรียญกับค่าประสบการณ์ เลเวลอัปเพิ่มเพดานพลังงาน |

**ตัวผลิตก็รวมร่างได้** — เอาแปลงผักสามอันมาต่อกันจะได้แปลงที่ปล่อยของขั้นสูงกว่าและชาร์จเร็วกว่า
นี่คือความลึกที่ทำให้เล่นยาว

## สายไอเทม

| สาย | ขั้น |
|---|---|
| ผัก | เมล็ดพันธุ์ → ต้นกล้า → ผักกาด → ตะกร้าผัก → ลังผัก → รถเข็นผัก |
| ไม้ | กิ่งไม้ → ท่อนไม้ → ซุง → ไม้แปรรูป → รั้วไม้ |
| น้ำ | หยดน้ำ → ถังน้ำ → โอ่งน้ำ → บ่อน้ำ |
| เหรียญ | เหรียญ → กองเหรียญ → ถุงเงิน → หีบสมบัติ |
| ตัวผลิต | แปลงผัก / กองไม้ อย่างละ 3 ขั้น |

## สิ่งที่ยกมาจากเวอร์ชันฟาร์มทั้งดุ้น

- **ระบบเสียง** สังเคราะห์ด้วย Web Audio ทั้งหมด — สายผสมเสียง 6 สาย, ducking, round-robin, สุ่มพิตช์
- **ชั้น juice** — อนุภาค ตัวเลขลอย สั่นจอ หยุดเวลา
- **การสุ่มแบบกำหนดผลได้** และ **เซฟที่มีเวอร์ชัน**
- **ตัวรวมไฟล์เดียว** ที่มีตัวตรวจสอบว่าสไตล์กับสคริปต์ไม่หายไป

ไม่มีไฟล์ภาพหรือไฟล์เสียงเลยสักไฟล์ ไอคอนไอเทมทุกชิ้นวาดด้วยโค้ดบน Canvas
