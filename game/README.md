# ไร่ดีมีสุข — ต้นแบบ Phase 0

ต้นแบบวงจรหลักของเกมปลูกผัก ตามเอกสารออกแบบใน [`../docs/GAME_DESIGN.md`](../docs/GAME_DESIGN.md)

**หน้าที่เดียวของเฟสนี้คือตอบคำถามว่า "สนุกไหม"** ยังไม่ใช่การสร้างเกมให้ครบ

## วิธีเอาไปเล่น

**แบบง่ายที่สุด — ไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไร**

```bash
npm install
npm run bundle     # ได้ dist-single/rai-dee.html ~41 kB
```

แล้วดับเบิลคลิกไฟล์ `dist-single/rai-dee.html` ได้เลย — ฝัง CSS กับ JS ไว้ในไฟล์ทั้งหมด
ส่งต่อทางแชตหรืออีเมลได้ เปิดออฟไลน์ได้ และเซฟเกมลง localStorage ของเบราว์เซอร์

> ไฟล์เดียวจบเพราะเสียงทั้งหมดสังเคราะห์ด้วย Web Audio และภาพวาดด้วย Canvas
> ไม่มีไฟล์เสียงหรือไฟล์ภาพให้ต้องแนบไปด้วยเลย

**แบบพัฒนาต่อ**

```bash
npm run dev        # เซิร์ฟเวอร์พัฒนา แก้โค้ดแล้วเห็นผลทันที
npm run build      # ตรวจชนิดข้อมูล + สร้างไฟล์แจกจ่าย
npm run sim        # เครื่องมือจำลองสมดุล — เล่นเอง 40 วันด้วย 5 กลยุทธ์
```

## วิธีเล่น

เลือกเครื่องมือด้วยปุ่ม `1`–`5` แล้วคลิกที่แปลง · **ลากค้างเพื่อทำงานต่อเนื่อง** · `เว้นวรรค` เข้านอน

พรวนดิน → ปลูก → รดน้ำทุกวัน → เก็บเกี่ยว → ขาย → ซื้อเมล็ดเพิ่ม
