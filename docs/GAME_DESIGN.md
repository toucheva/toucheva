# ไร่ดีมีสุข — เอกสารออกแบบเกม (GDD v0.1)

> เกมปลูกผักแนว cozy farming sim + management ที่ออกแบบให้ "นั่งเล่นยาวๆ ได้"
> สถานะ: **ร่างออกแบบ ยังไม่เริ่มเขียนโค้ด** — รอเคาะขอบเขตก่อน

## 0. สรุปผู้บริหาร

| หัวข้อ | สรุป |
|---|---|
| ชื่อชั่วคราว | ไร่ดีมีสุข (Rai Dee) |
| แนว | Cozy farming simulation + resource management + light RPG |
| แพลตฟอร์ม | เว็บเบราว์เซอร์ (desktop-first, รองรับ tablet), เล่นออฟไลน์ได้ |
| มุมกล้อง | 2D top-down แบบตาราง (grid) |
| ผู้เล่น | 1 คน (co-op เป็นแผนหลัง v1.0) |
| เวลาเล่นถึงจบเนื้อเรื่อง | ~45–60 ชั่วโมง |
| เวลาเล่นจนหมดเนื้อหา | ~150 ชั่วโมง + endless |
| จำนวนระบบ | 29 ระบบ ปลดล็อกทีละอย่างตลอด 100 ชั่วโมงแรก |
| จำนวนเควส | ~190 เควสที่เขียนมือ + ตัวสร้างเควสไม่จำกัด |

**ทำไมถึงเล่นยาวได้** — เกมนี้ไม่ได้ยืดอายุด้วยการให้ตัวเลขโตขึ้นเฉยๆ แต่ใช้สามอย่างซ้อนกัน:

1. **ปลดล็อกระบบใหม่ตลอด** — ทุก 2–4 ชั่วโมงเล่นจะมีของเล่นใหม่ที่เปลี่ยนวิธีคิด ไม่ใช่แค่ตัวเลขใหญ่ขึ้น
2. **ระบบที่ลึกจริงตอนปลายเกม** — พันธุกรรมเมล็ด ดิน และตลาด เป็นระบบที่ "แก้โจทย์" ได้ไม่รู้จบ ไม่ใช่แค่กดซ้ำ
3. **ทุกวันในเกมไม่เหมือนกัน** — อากาศ ราคา เหตุการณ์ คำขอจาก NPC สุ่มใหม่ทุกวัน ทำให้ไม่มีวัน "ทำแบบเดิม"

## 1. เสาหลักการออกแบบ (Design Pillars)

ทุกการตัดสินใจต้องผ่าน 5 ข้อนี้ ถ้าฟีเจอร์ไหนขัดข้อใดข้อหนึ่ง ให้ตัดทิ้ง

| # | เสาหลัก | หมายความว่า | ตัวอย่างที่ "ตก" |
|---|---|---|---|
| P1 | **ไม่มีวันที่เสียเปล่า** | ทุกวันในเกมต้องได้อะไรกลับไปอย่างน้อย 1 อย่าง | เควสที่ต้องรอ 5 วันโดยทำอะไรไม่ได้เลย |
| P2 | **เลือกยาก ไม่ใช่กดเยอะ** | ความสนุกมาจากการเลือกใช้ทรัพยากรจำกัด | ระบบที่คำตอบดีที่สุดมีแค่คำตอบเดียวเสมอ |
| P3 | **ระบบต้องคุยกัน** | ทุกระบบใหม่ต้องเชื่อมกับอย่างน้อย 2 ระบบเดิม | มินิเกมที่ให้เหรียญอย่างเดียว จบในตัวเอง |
| P4 | **ให้อภัยเสมอ** | พลาดแล้วเสียเวลา ไม่ใช่เสียของถาวร | พืชตายแล้วสูญเมล็ดหายากถาวร |
| P5 | **ยกภาระงานซ้ำออกไปเรื่อยๆ** | สิ่งที่ทำจนชำนาญแล้ว ต้องมีทางทำให้อัตโนมัติ | ต้องรดน้ำ 200 ช่องด้วยมือตลอดเกม |

## 2. วงจรการเล่น 3 ชั้น

### ชั้นที่ 1 — วงจรนาที (30 วินาที)
```
เดินไปแปลง → เลือกเครื่องมือ → ลงมือ (ขุด/ปลูก/รดน้ำ/เก็บ) → เห็นผลทันที + เสียง + ตัวเลขเด้ง
```
ต้องรู้สึกดีที่ "มือ" ล้วนๆ: จังหวะ เสียง แอนิเมชัน เก็บผักแล้วมันต้องกรุบ

### ชั้นที่ 2 — วงจรวัน (12 นาทีจริง = 1 วันในเกม)
```
ตื่น 06:00 → เช็คอากาศ + ราคาตลาด + กระดานเควส
   → จัดลำดับงานวันนี้ด้วย Stamina ที่มีจำกัด
   → ลงแปลง / เข้าเมือง / ไปสำรวจ / คุยกับ NPC
   → ขายของหน้าฟาร์ม → เข้านอน 02:00
   → สรุปวัน: รายรับ ค่าประสบการณ์ เหตุการณ์พรุ่งนี้
```
**หัวใจคือ Stamina** — ทำได้ไม่หมดทุกอย่าง ต้องเลือกว่าวันนี้จะเป็นวันของอะไร

### ชั้นที่ 3 — วงจรฤดู/ปี (28 วัน = ~5.5 ชั่วโมงจริง)
```
ต้นฤดู: วางแผนว่าจะปลูกอะไร ลงทุนอะไร รับสัญญาส่งของอันไหน
กลางฤดู: บริหารความเสี่ยง (โรค แมลง อากาศ) + สะสมทุน
ปลายฤดู: เก็บเกี่ยวใหญ่ + เทศกาล + ประกวด
สิ้นฤดู: พืชล้มตายหมด → รีเซ็ตแปลง → ตัดสินใจอัปเกรดใหญ่ 1 อย่าง
```

**1 ปีในเกม = 4 ฤดู × 28 วัน = 112 วัน ≈ 22 ชั่วโมงจริง**

## 3. โลกและเรื่องราว

### ฉาก
**"บ้านหนองผักหวาน"** หมู่บ้านเกษตรในหุบเขา เคยเป็นแหล่งผักส่งเมืองที่ดังที่สุด แต่ตอนนี้คนหนุ่มสาวย้ายเข้าเมืองหมด ตลาดกลางร้าง เหลือแค่คนแก่กับที่ดินรกร้าง

### จุดเริ่ม
ผู้เล่นได้รับมรดกเป็น **ไร่ร้างของตา** พร้อมสมุดบันทึกเก่าที่เขียนไม่จบ กับหนี้ค้างชำระก้อนหนึ่ง

### ตัวขัดแย้ง
บริษัท **"เกษตรพัฒนา"** กำลังกว้านซื้อที่ดินทั้งหุบเขาเพื่อทำเกษตรอุตสาหกรรมเชิงเดี่ยว ไม่ใช่ผู้ร้ายแบบการ์ตูน — พวกเขาเสนอราคาดี มีเหตุผล และ NPC บางคนก็อยากขายจริงๆ ผู้เล่นต้องพิสูจน์ว่าทางเลือกอีกแบบก็อยู่รอดได้

### โครงเรื่องหลัก 5 บท

| บท | ชื่อ | ปลดล็อกที่ | แก่นเรื่อง | เควสหลัก |
|---|---|---|---|---|
| 1 | ดินที่ยังหายใจ | เริ่มเกม | เรียนรู้พื้นฐาน ฟื้นแปลงแรก | 10 |
| 2 | ตลาดที่ปิดไป | ฤดู 2 | เปิดตลาดนัดชุมชนอีกครั้ง | 12 |
| 3 | สมุดที่เขียนไม่จบ | ปี 1 ปลาย | ตามหาพันธุ์ผักพื้นบ้านที่หายไป 7 ชนิด | 14 |
| 4 | ข้อเสนอที่ปฏิเสธยาก | ปี 2 | เกษตรพัฒนายื่นข้อเสนอกับทั้งหมู่บ้าน | 15 |
| 5 | หุบเขาที่เรากลับมา | ปี 3 | สร้างเครือข่ายเกษตรกร + ตอนจบ 3 แบบ | 11 |

**ตอนจบ 3 แบบ** (ตัดสินจากสถิติที่สะสมมา ไม่ใช่การกดเลือก): ไร่เดี่ยวระดับตำนาน / สหกรณ์ชุมชน / ร่วมมือกับบริษัทแบบมีเงื่อนไข — เล่นต่อได้หลังจบทุกแบบ

## 4. รายการระบบทั้งหมด (29 ระบบ)

จัดเป็น 6 กลุ่ม แต่ละระบบระบุ: ปลดล็อกเมื่อไหร่ · เชื่อมกับระบบไหน · ทำให้เล่นยาวยังไง

### กลุ่ม A — ฐานราก (Core)

**A1 · ระบบเวลา ฤดูกาล และอากาศ** — ปลดล็อก: เริ่มเกม
1 วัน = 12 นาทีจริง (06:00–02:00) · 4 ฤดู × 28 วัน · อากาศ 9 แบบ (แดดจัด/มีเมฆ/ฝนปรอย/ฝนหนัก/พายุ/ลมแรง/หมอก/น้ำค้างแข็ง/ร้อนจัด) · **พยากรณ์ล่วงหน้า 3 วัน** เพื่อให้วางแผนได้
เชื่อมกับ: ทุกระบบ · เล่นยาวเพราะ: ทำให้แต่ละวันไม่เหมือนกันโดยไม่ต้องเพิ่มเนื้อหา

**A2 · ระบบพลังงาน (Stamina)** — ปลดล็อก: เริ่มเกม
เริ่มที่ 120 → ขยายได้ถึง 400 · รดน้ำ 2 · ขุด 5 · ถางหญ้า 4 · เก็บเกี่ยว 1 · หมดแล้วเป็นลม (เสียครึ่งวัน ไม่เสียของ ตาม P4)
เชื่อมกับ: อาหาร สกิล เครื่องมือ อัตโนมัติ · เล่นยาวเพราะ: เป็นตัวบังคับให้ต้อง "เลือก" ทุกวัน

**A3 · ระบบแปลงปลูกและดิน** — ปลดล็อก: เริ่มเกม (ความลึกเปิดที่ชั่วโมง 6)
แต่ละช่องเก็บค่า: **N-P-K (0–100 ต่อธาตุ) · pH (4.5–8.5) · อินทรียวัตถุ (0–100) · ความชื้น · โรคสะสม**
พืชแต่ละชนิดมี "ช่วงเหมาะสม" ของตัวเอง → ผลผลิตและคุณภาพคำนวณจากความเหมาะสม
ปลูกพืชเดิมซ้ำ = ธาตุพร่อง + โรคสะสม → บังคับให้ต้อง **หมุนเวียนพืช (crop rotation)** ปลูกพืชตระกูลถั่วเพื่อเติมไนโตรเจน ปลูกพืชคลุมดินเพื่อพักแปลง
เชื่อมกับ: ปุ๋ยหมัก ปศุสัตว์ พันธุกรรม โรคพืช · เล่นยาวเพราะ: เป็นปริศนาการวางผังที่ยากขึ้นเรื่อยๆ เมื่อแปลงใหญ่ขึ้น

**A4 · ระบบพืชผัก** — ปลดล็อก: เริ่มเกม
**72 รายการ**: ผักตามฤดู 52 (13 ต่อฤดู) + พืชยืนต้น 8 (ไม้ผล/สมุนไพร) + พันธุ์ป่า/หายาก 12
แต่ละชนิดมี: ระยะเวลาโต · ระยะการเติบโต 4–6 ขั้น · เก็บซ้ำได้ไหม · ผลผลิตต่อครั้ง · ช่วงดินที่เหมาะ · ราคาฐาน · **คุณภาพ 1–5 ดาว** (ตัวคูณราคา ×1.0 / ×1.25 / ×1.6 / ×2.1 / ×3.0)
เชื่อมกับ: ดิน พันธุกรรม แปรรูป ตลาด สารานุกรม

**A5 · ระบบน้ำและชลประทาน** — ปลดล็อก: ชั่วโมง 3
บ่อน้ำมีปริมาณจำกัด เติมด้วยฝน · ยกระดับ: บัวรดน้ำ → บ่อบาดาล → สปริงเกลอร์ → น้ำหยดอัตโนมัติ (แม่นยำกว่า ประหยัดน้ำกว่า)
เชื่อมกับ: อากาศ ดิน อัตโนมัติ ภัยพิบัติ · เล่นยาวเพราะ: เปลี่ยนงานที่น่าเบื่อที่สุดให้เป็นโจทย์วางระบบท่อ

**A6 · ระบบเครื่องมือและการอัปเกรด** — ปลดล็อก: เริ่มเกม
6 เครื่องมือ (จอบ บัวรดน้ำ เคียว ขวาน ค้อน แห) × 5 ระดับวัสดุ · อัปเกรดแล้ว **ลด Stamina + เพิ่มพื้นที่ทำงานต่อครั้ง** (1 ช่อง → 3×3)
เชื่อมกับ: Stamina สกิล เหมือง เศรษฐกิจ

### กลุ่ม B — ความลึก (Depth)

**B1 · ระบบพันธุกรรมและการผสมเมล็ด** ⭐ ระบบเรือธงของปลายเกม — ปลดล็อก: ชั่วโมง 20
เมล็ดทุกเมล็ดมี **6 ยีน**: ผลผลิต · ความเร็วโต · ต้านโรค · ทนอากาศ · รสชาติ · เก็บรักษา — แต่ละยีนมี allele 3 ระดับ
ผสมข้ามพันธุ์ 2 ต้น → ลูกได้ยีนแบบเมนเดล + โอกาสกลายพันธุ์ 3% (ยีนระดับ 4 ที่ซื้อไม่ได้)
มี **ตู้เก็บเมล็ด (Seed Vault)** สำหรับสายพันธุ์ที่เพาะได้เอง ตั้งชื่อเองได้ แชร์รหัสเมล็ดให้เพื่อนได้
เชื่อมกับ: พืช ดิน โรค ประกวด วิจัย · เล่นยาวเพราะ: **เป็นระบบที่ไม่มีคำว่า "จบ"** — ผู้เล่นตั้งเป้าเองว่าจะเพาะพันธุ์อะไร

**B2 · ระบบศัตรูพืชและโรค** — ปลดล็อก: ชั่วโมง 5
ศัตรูพืช 8 ชนิด (เพลี้ย หนอน ไร ราน้ำค้าง รากเน่า ฯลฯ) · ระบาดตามอากาศ+ความหนาแน่นของพืชชนิดเดียวกัน
วิธีรับมือ 4 ทาง: **สารเคมี** (เร็ว แต่ทำลายดิน + ลดคุณภาพ) · **สมุนไพรไล่แมลง** (ช้ากว่า ปลอดภัย) · **แมลงตัวห้ำ** (ลงทุนก่อน ได้ผลยาว) · **ปลูกพืชไล่แมลงแซม** (ฟรี แต่เสียพื้นที่)
เชื่อมกับ: ดิน อากาศ พันธุกรรม คุณภาพ · เล่นยาวเพราะ: มีคำตอบหลายแบบที่แลกกันจริง (P2)

**B3 · ระบบปุ๋ยหมักและวงจรของเสีย** — ปลดล็อก: ชั่วโมง 8
เศษพืช + มูลสัตว์ + เศษอาหาร → กองปุ๋ยหมัก (ใช้เวลา 6–10 วัน) → ปุ๋ยอินทรีย์เกรดต่างๆ
มีบ่อไส้เดือน (ปุ๋ยเกรดสูง) และน้ำหมักชีวภาพ
เชื่อมกับ: ดิน ปศุสัตว์ ทำอาหาร · เล่นยาวเพราะ: ทำให้ "ของเหลือ" มีค่า ผู้เล่นเริ่มออกแบบฟาร์มเป็นระบบปิด

**B4 · ระบบปศุสัตว์** — ปลดล็อก: ชั่วโมง 10
ไก่ · เป็ด · แพะ · วัว · ผึ้ง · ไส้เดือน — แต่ละชนิดมีค่าความสุข ให้ผลผลิตต่างกัน
**ผึ้ง** เพิ่มอัตราติดผลของพืชรอบรัง 15% · **สัตว์** ให้มูลเข้าระบบปุ๋ยหมัก · **เป็ด** กินหอยทากในแปลง
เชื่อมกับ: ปุ๋ยหมัก ดิน ทำอาหาร ความสัมพันธ์ · เล่นยาวเพราะ: เชื่อมกลับเข้าระบบดินโดยตรง ไม่ใช่ระบบแยก

**B5 · ระบบแปรรูปและทำอาหาร** — ปลดล็อก: ชั่วโมง 7
เครื่องแปรรูป 9 แบบ: โรงหมัก (ผักดอง กิมจิ) · เครื่องอบแห้ง · เครื่องคั้นน้ำ · หม้อแยม · โรงสี · เตาอบ · ถังหมักน้ำส้มสายชู · ห้องบ่ม · เครื่องบรรจุ
**มูลค่าเพิ่ม ×1.8 ถึง ×5.0** แต่แลกกับเวลาและพื้นที่ · สูตรอาหาร 90 สูตร ให้บัฟชั่วคราว (Stamina / ความเร็ว / โชคหาของ)
เชื่อมกับ: พืช ปศุสัตว์ ตลาด NPC เทศกาล · เล่นยาวเพราะ: เป็นชั้นเศรษฐกิจที่สอง ทำให้ผักราคาถูกกลับมามีค่า

**B6 · ระบบตลาดและเศรษฐกิจพลวัต** ⭐ — ปลดล็อก: ชั่วโมง 4
ราคาไม่คงที่:
```
ราคาวันนี้ = ราคาฐาน × ตัวคูณฤดู × (1 − อุปทานสะสม/K) × ความต้องการเหตุการณ์ × สุ่ม(±8%)
```
ขายผักชนิดเดียวเยอะๆ ติดกัน → **ราคาตกจริง** (ฟื้นตัววันละ 12%) บังคับให้ต้องปลูกหลากหลาย
ช่องทางขาย 5 แบบ: ลังหน้าฟาร์ม (ง่าย ราคาต่ำ) · พ่อค้าคนกลาง · **ตลาดนัดวันเสาร์** (ตั้งราคาเอง ต่อรองกับลูกค้า) · **สัญญาส่งของ** (ล็อกราคา ปรับล่วงหน้าถ้าส่งไม่ครบ) · **สมาชิก CSA** (รายได้ประจำเดือน แลกกับต้องส่งตะกร้าผักหลากชนิดทุกสัปดาห์)
เชื่อมกับ: ทุกอย่างที่ผลิตได้ · เล่นยาวเพราะ: เป็นโจทย์บริหารความเสี่ยงที่เล่นได้ไม่จบ

**B7 · ระบบสกิลและเพิร์ก** — ปลดล็อก: ชั่วโมง 2
6 สาย × 10 ระดับ: **เกษตร · ปศุสัตว์ · ครัว · ค้าขาย · ช่างฝีมือ · ธรรมชาติวิทยา**
ที่ระดับ 5 และ 10 เลือกเพิร์ก **2 จาก 4** (สลับได้ที่ศาลเจ้า เสียค่าธรรมเนียม ตาม P4)
เชื่อมกับ: ทุกระบบ · เล่นยาวเพราะ: สร้าง build ได้หลายแบบ ทำให้เล่นรอบสองต่างออกไป

### กลุ่ม C — ฟาร์มและพื้นที่

## 5. ระบบเควส — "ให้มีเควสเยอะ" แบบที่ไม่ใช่งานซ้ำ

### 5.1 ประเภทเควส 6 แบบ

| แบบ | จำนวน | ที่มา | อายุ | ให้อะไร |
|---|---|---|---|---|
| **เนื้อเรื่องหลัก** | 62 | เขียนมือ | ถาวร | ปลดล็อกระบบ + พื้นที่ |
| **เส้นเรื่อง NPC** | 78 | เขียนมือ (16 คน × 4–6) | ถาวร | สูตร บริการ ความสัมพันธ์ |
| **ชุดบริจาคศูนย์ชุมชน** | 48 ชุด (8 หมวด × 6) | เขียนมือ | ถาวร | ฟื้นฟูสิ่งอำนวยความสะดวกในหมู่บ้าน |
| **กระดานเควสรายวัน** | 3 ใบ/วัน | สร้างอัตโนมัติ | 1–3 วัน | เงิน วัตถุดิบ ค่าความสัมพันธ์ |
| **สัญญาส่งของ** | 2–4 ใบพร้อมกัน | สร้างอัตโนมัติ | 1 ฤดู | เงินก้อน + ชื่อเสียง |
| **ความสำเร็จ** | 160 | เขียนมือ | ถาวร | ฉายา ของตกแต่ง เพิ่มเพดาน |

**รวมที่เขียนมือ ~190 เควส + ~1,100 เควสสร้างอัตโนมัติต่อปีในเกม**

### 5.2 ตัวสร้างเควสอัตโนมัติ

ไม่ใช่การสุ่มมั่ว แต่ใช้ **เทมเพลต 40 แบบ × ช่องเติม (slot) ที่คัดตามสถานะเกมจริง**

```
เทมเพลต: "ส่งของตามสั่ง"
  [NPC] ต้องการ [สินค้า] จำนวน [n] คุณภาพอย่างน้อย [ดาว] ภายใน [วัน]
  รางวัล: [เงิน] + [ค่าความสัมพันธ์] + [โอกาสได้ของพิเศษ]

กติกาการเติมช่อง:
  - NPC เลือกจากคนที่ผู้เล่นรู้จักแล้ว และเลือกคนที่ไม่ได้คุยนานที่สุดก่อน
  - สินค้าเลือกจากของที่ผู้เล่น "ผลิตได้แล้ว" หรือ "ผลิตได้ในอีก 2 วัน"
  - n และ ดาว ปรับตามกำลังผลิตจริงของผู้เล่น (ยากพอให้ต้องขยับ ไม่ยากจนทำไม่ได้)
  - ห้ามออกเทมเพลตเดิมซ้ำภายใน 5 วัน
  - 1 ใน 3 ใบต่อวันต้องเป็นเควสที่ "ทำให้ต้องลองสิ่งที่ยังไม่เคยทำ"
```

**40 เทมเพลตแบ่งเป็น**: ส่งของ 8 · สำรวจ/หาของ 7 · แปรรูป 6 · ดูแลฟาร์ม 5 · สังคม 5 · แข่งขัน 4 · ปริศนา/ทดลอง 5

### 5.3 ตัวอย่างเควสจริง

**[หลัก บทที่ 3] "หน้าที่หายไป"**
สมุดของตามีหน้า 41–48 ถูกฉีก ยายบอกว่าตาเคยฝากไว้กับคน 3 คนในหมู่บ้าน แต่ละคนจะคืนให้ก็ต่อเมื่อผู้เล่นทำสิ่งที่ตาเคยสัญญาไว้กับพวกเขาแทน → แตกเป็น 3 เควสย่อยที่ใช้ระบบต่างกันคนละระบบ (แปรรูป / ปศุสัตว์ / ตกปลา) → ได้เบาะแสพันธุ์ "ผักหวานหุบเขา"

**[NPC] "ครูสมพงษ์ · ฉากที่ 4"**
ครูเกษียณที่พยายามสอนเด็กปลูกผักในโรงเรียน แต่ดินโรงเรียนเป็นดินทรายจัด → ผู้เล่นต้องวิเคราะห์ดิน ทำปุ๋ยหมัก 3 กระสอบ และเลือกพันธุ์ที่เหมาะ → ปลดล็อก "เครื่องวัดดินแบบพกพา" (แสดงค่าดินบนแปลงตลอดเวลา — QoL สำคัญที่ได้มาจากเนื้อเรื่อง)

**[รายวัน · สร้างอัตโนมัติ] "ป้ามาลีขอผักกาดขาว"**
ป้ามาลีต้องการผักกาดขาว 8 หัว คุณภาพ 3 ดาวขึ้นไป ภายใน 2 วัน · รางวัล 640 เหรียญ + ความสัมพันธ์ +2 + สูตรกิมจิ (ครั้งแรกเท่านั้น)

**[สัญญา] "ส่งออกล็อตแรก"**
ส่งผักสลัด 5 ชนิด รวม 200 หน่วย คุณภาพเฉลี่ย 4 ดาว ภายในสิ้นฤดู · มัดจำล่วงหน้า 2,000 · ส่งครบได้อีก 12,000 · **ส่งไม่ครบเสียมัดจำ + ชื่อเสียง −1**

**[ชุดบริจาค] "หมวดฤดูฝน"**
ต้องการ: เห็ดโคน 1 · ปลาช่อนตัวใหญ่ 1 · ข้าวโพดหวาน 5 ดาว 1 · น้ำผึ้งป่า 1 · เผือกหอม 1 · เมล็ดพันธุ์ที่ตัวเองเพาะเอง 1 → เปิด **สะพานข้ามลำห้วย** เข้าที่ราบสูง

**[ความสำเร็จ] "นักผสมพันธุ์"**
เพาะพันธุ์ที่มียีนระดับ 4 ครบ 3 ยีนในต้นเดียว → ฉายา "ผู้ปลุกยีน" + ปลดล็อกตู้เมล็ดชั้นสูง

### 5.4 กติกาคุณภาพเควส (ห้ามละเมิด)
- ห้ามมีเควส "ไปเก็บของ 20 ชิ้นแล้วกลับมา" ที่ไม่มีเหตุผลในเรื่อง
- ทุกเควสรายวันต้องทำเสร็จได้ภายในวันเดียวถ้าผู้เล่นตั้งใจ
- เควสที่มีเส้นตาย ต้องเตือนล่วงหน้าอย่างน้อย 1 วัน
- ห้ามให้เควสที่ผู้เล่นทำไม่ได้ด้วยระบบที่ยังไม่ปลดล็อก

## 8. ระบบต่อต้านความเบื่อ

ปัญหาใหญ่ที่สุดของเกมแนวนี้คือ **ชั่วโมงที่ 15–30 ที่ผู้เล่นเริ่มรู้สึกว่าทำแบบเดิมทุกวัน** วิธีแก้:

1. **ความแปรผันรายวันบังคับ** — ทุกวันต้องมีอย่างน้อย 1 อย่างที่ไม่เหมือนเมื่อวาน (อากาศ / ราคาที่พุ่ง-ตก / เหตุการณ์ / เควส)
2. **ยกงานซ้ำออกทันทีที่เชี่ยวชาญ** — พอผู้เล่นรดน้ำเก่งแล้ว ต้องได้สปริงเกลอร์ ไม่ใช่ให้รดน้ำต่อไปอีก 50 ชั่วโมง
3. **โจทย์ที่ผู้เล่นตั้งเอง** — พันธุกรรม การจัดผัง และตราสินค้า เปิดให้ผู้เล่นตั้งเป้าหมายเอง ซึ่งเป็นเชื้อเพลิงที่ไม่มีวันหมด
4. **จังหวะหนัก-เบา** — ต้นฤดูวางแผน (เบา) กลางฤดูบริหาร (กลาง) ปลายฤดูเก็บเกี่ยว+เทศกาล (หนัก) แล้ววนใหม่
5. **ไม่ปิดกั้นด้วยเวลารอ** — ถ้าต้องรอพืชโต ต้องมีอย่างอื่นให้ทำเสมอ (P1)
6. **โหมดเร่งความเร็ว ×2** สำหรับวันที่ไม่มีอะไรทำ

## 9B. ภาคเสียง (Audio Design) — ฉบับเต็ม

> เกมที่นั่งเล่นทีละ 3 ชั่วโมง เสียงคือสิ่งที่ทำให้ "อยู่ต่อ" หรือ "ปิดลำโพง"
> ภาคนี้ออกแบบทั้งดนตรี บรรยากาศ เอฟเฟกต์ ระบบผสมเสียง และงบทรัพยากร

### 9B.1 เสาหลักด้านเสียง

| # | เสาหลัก | หมายความว่า |
|---|---|---|
| S1 | **เสียงคือฟีดแบ็ก ไม่ใช่ของประดับ** | ทุกการกระทำต้องมีเสียงตอบกลับใน 30 มิลลิวินาที ผู้เล่นต้องรู้ว่า "ติด" หรือ "ไม่ติด" โดยไม่ต้องมอง |
| S2 | **เสียงบอกสถานะโลก** | ได้ยินแล้วรู้ว่าตอนนี้ฤดูอะไร กี่โมง ฝนกำลังจะตกไหม โดยไม่ต้องเปิดยูไอ |
| S3 | **ฟังร้อยชั่วโมงแล้วไม่ล้า** | ทุกเสียงที่เล่นบ่อยต้องมีตัวแปร 4–6 แบบ + สุ่มระดับเสียงและพิตช์ |
| S4 | **มีเสียงเด่นแค่ตอนที่ควรเด่น** | เสียงรางวัลใหญ่ต้องดังกว่าจริง และต้องหรี่เสียงอื่นให้ (ducking) |
| S5 | **เล่นแบบปิดเสียงก็ยังเล่นได้** | ข้อมูลสำคัญทุกอย่างที่ส่งด้วยเสียง ต้องมีคู่ที่เป็นภาพเสมอ |

### 9B.2 อัตลักษณ์เสียงดนตรี

**เครื่องดนตรีหลัก** — ผสมพื้นบ้านไทยกับ cozy acoustic เพื่อให้จำได้ว่าเป็นเกมนี้ ไม่ใช่เกมฟาร์มทั่วไป

- **นำทำนอง**: ขลุ่ยเพียงออ · ซออู้ (เฉพาะฉากซึ้ง) · กีตาร์โปร่งดีดนิ้ว
- **ประกอบ**: ระนาดเอกตีเบา (ใช้ไม้นวม) · คาลิมบา · เปียโนไฟฟ้าโทนนุ่ม
- **จังหวะ**: กลองรำมะนาเบาๆ · ฉิ่ง · เชคเกอร์ · เบสอัพไรต์
- **พื้นเสียง**: แพดสังเคราะห์อุ่นๆ ไว้ใต้ทุกอย่าง

**หลักการเรียบเรียง**: ทำนองสั้น จำง่าย 8 ห้อง วนได้โดยไม่น่ารำคาญ · ความยาวลูปละ 90–150 วินาที · **ห้ามใส่ทำนองเด่นในเพลงที่เล่นทุกวัน** (เพลงฟาร์มต้องฟังผ่านๆ ได้ ส่วนเพลงเทศกาลค่อยเด่น)

### 9B.3 รายการเพลง (28 ชิ้น จาก 16 บทประพันธ์)

ใช้เทคนิค **ชั้นเสียง (stem layering)** — แต่งเพลงหลัก 1 เพลงต่อฤดู แล้วเปลี่ยนเครื่องดนตรีตามเวลาของวัน ได้ 3 เวอร์ชันจากงานแต่งครั้งเดียว ประหยัดงานแต่งลง 60%

| กลุ่ม | รายการ | หมายเหตุ |
|---|---|---|
| ฟาร์ม | ฤดูร้อน · ฤดูฝน · ฤดูหนาว · ฤดูแล้ง | แต่ละเพลงมี 3 ชั้น: เช้า (ขลุ่ย+กีตาร์) / กลางวัน (เต็มวง) / ค่ำ (เปียโน+แพด) |
| หมู่บ้าน | เพลงหมู่บ้านกลางวัน · กลางคืน | |
| สถานที่ | ร้านค้า · ร้านเหล้าตอนค่ำ · ป่า · ริมน้ำ · โรงเรือน (เกือบเงียบ) | |
| เหมือง | ชั้น 1–20 · ชั้น 21–40 · ชั้น 41–60 | ยิ่งลึกยิ่งเบาบางและกดดัน |
| เทศกาล | ตลาดนัดใหญ่ · ประกวดผัก · งานวัด · เทศกาลฤดูหนาว | เด่น สนุก มีเครื่องเป่าเยอะ |
| เนื้อเรื่อง | ธีมของตา (ซออู้) · ธีมเกษตรพัฒนา (เย็นชา สังเคราะห์) · ธีมชัยชนะ | ธีมของตาจะโผล่แทรกเป็นชิ้นเล็กๆ ตลอดเกม |
| พิเศษ | หน้าชื่อเกม · งานแต่ง · ตอนจบ 3 แบบ · เครดิต | |

### 9B.4 ระบบดนตรีปรับตัว (Adaptive Music)

เพลงไม่ได้เล่นวนเฉยๆ แต่ตอบสนองสถานการณ์:

| ตัวกระตุ้น | สิ่งที่เกิดกับเสียง |
|---|---|
| เปลี่ยนช่วงเวลาของวัน | เปลี่ยนชั้นเครื่องดนตรี (crossfade 4 วินาที ไม่หยุดเพลง) |
| ฝนเริ่มตก | ถอดชั้นจังหวะออก เหลือแพดกับเปียโน + เพิ่มรีเวิร์บ |
| พายุ | หยุดเพลงทั้งหมด เหลือแต่เสียงบรรยากาศ (เงียบคือความตึงเครียด) |
| **Stamina ต่ำกว่า 15%** | ใส่ฟิลเตอร์ตัดเสียงแหลม + หัวใจเต้นเบาๆ — บอกสถานะโดยไม่ต้องมองยูไอ (S2) |
| โรคระบาดในแปลง | ลดชั้นทำนองลง เหลือพื้นเสียงหม่น |
| เดินเข้าเขตเทศกาล | เพิ่มชั้นเครื่องเป่าและกลองทีละชั้นตามระยะทาง |
| ปลดล็อกระบบใหม่ | หยุดเพลง 1 วินาที → สติงเกอร์ → เพลงกลับมา |
| นาทีสุดท้ายก่อนหมดวัน | เพิ่มเสียงระฆังเบาๆ ทุก 30 วินาที |

### 9B.5 เสียงบรรยากาศแบบชั้น (Layered Ambience)

พื้นเสียงประกอบด้วย **4 ชั้นที่ผสมกันแบบสด**:

```
ชั้น 1 พื้นฐานตามพื้นที่   ลมในทุ่ง / เสียงเมือง / เสียงป่า / เสียงถ้ำ
ชั้น 2 ตามเวลา             เช้า: ไก่ขัน+นกกระจอก | กลางวัน: จักจั่น | ค่ำ: จิ้งหรีด+กบ | ดึก: นกฮูก
ชั้น 3 ตามอากาศ            ฝนบนหลังคาสังกะสี / ลมแรง / ฟ้าร้องระยะไกล / ความเงียบของหมอก
ชั้น 4 ตามระยะใกล้วัตถุ    ใกล้บ่อ: กบ+น้ำ | ใกล้เล้าไก่: ไก่ | ใกล้รังผึ้ง: หึ่ง | ใกล้โรงหมัก: ฟองปุด
```

ทุกชั้นเฟดเข้า-ออก 2–3 วินาที · ชั้น 4 ใช้การกระจายเสียงซ้าย-ขวาตามตำแหน่งจริงบนจอ

**เสียงประจำฤดูที่ต้องได้ยินแล้วรู้ทันที**: ร้อน = จักจั่นดังแสบ · ฝน = กบกับฝนตกบนใบไม้ · หนาว = ลมกับความเงียบ · แล้ง = ลมหอบฝุ่นกับใบไม้แห้ง

### 9B.6 รายการเสียงเอฟเฟกต์ (~186 เสียง)

| หมวด | จำนวน | รายละเอียด |

- มีตัวแปรอย่างน้อย 4 ไฟล์ และวนแบบ round-robin (ห้ามสุ่มซ้ำตัวเดิมติดกัน)
- สุ่มพิตช์ ±4% และระดับเสียง ±1.5 dB ทุกครั้ง
- มีเพดานจำนวนเสียงพร้อมกัน (ฝีเท้า 2 · พืช 6 · ยูไอ 3)

### 9B.7 สถาปัตยกรรมระบบเสียง

```
เทคโนโลยี: Web Audio API ผ่าน Howler.js 2.2 (พินเวอร์ชัน)
รูปแบบไฟล์: OGG Vorbis เป็นหลัก + M4A/AAC สำรองสำหรับ Safari
```

**สายผสมเสียง 6 สาย** (ผู้เล่นปรับแยกได้ทุกสาย)
```
Master
├── Music        เพลง (ค่าเริ่มต้น 70%)
├── Ambience     เสียงบรรยากาศ (80%)
├── SFX          เอฟเฟกต์การกระทำ (100%)
├── UI           เสียงหน้าจอ (85%)
├── Voice        เสียงพึมพำ NPC (90%)
└── Stinger      สติงเกอร์รางวัล (100%, ไม่ถูกหรี่)
```

**กลไกสำคัญ**
- **Audio sprite** — รวมเสียงสั้นทั้งหมดเป็นไฟล์เดียวต่อหมวด ลดจำนวนคำขอจาก 186 เหลือ 12
- **Voice pooling** — จองอินสแตนซ์ล่วงหน้า ไม่สร้างใหม่ตอนเล่น (กันสะดุด)
- **Ducking** — สติงเกอร์รางวัลหรี่สาย Music และ Ambience ลง 6 dB เป็นเวลา 800 มิลลิวินาที แล้วคืนแบบนุ่ม
- **การกระจายเสียงเชิงตำแหน่ง** — เสียงบนแผนที่แพนซ้าย-ขวาและเบาลงตามระยะจากกล้อง (ตัดที่ 12 ช่อง)
- **ปลดล็อกบริบทเสียง** — เบราว์เซอร์บล็อกเสียงจนกว่าผู้ใช้จะคลิกครั้งแรก → ต้องเรียก `resume()` ที่การกดครั้งแรกเสมอ ไม่งั้นเกมจะเงียบสนิทและหาบั๊กไม่เจอ
- **โหลดเป็นชั้น** — ยูไอ+ฟาร์มโหลดตอนเข้าเกม · เหมือง/เทศกาล/เมือง โหลดเมื่อใกล้ถึง
- **เร่งเวลา ×2** — เพลงไม่เร่งตาม (เพี้ยน) แต่เสียงบรรยากาศและเอฟเฟกต์เร่งได้

**งบทรัพยากร**
| ประเภท | บิตเรต | ขนาดรวมเป้าหมาย |
|---|---|---:|
| เพลง (28 ชิ้น, สเตอริโอ) | 128 kbps | ~34 MB |
| บรรยากาศ (22 ลูป, สเตอริโอ) | 112 kbps | ~11 MB |
| เอฟเฟกต์ (186 เสียง, โมโน) | 96 kbps | ~7 MB |
| **รวม** | | **~52 MB** |

### 9B.8 การเข้าถึงด้านเสียง

- **คำบรรยายเสียง (closed caption)** — เปิดได้ แสดงข้อความเช่น "[ฟ้าร้องระยะไกล]" "[โรงหมักทำงานเสร็จ]"
- **ตัวบ่งชี้ภาพคู่กับเสียงสำคัญทุกตัว** (S5) — พายุมา = ไอคอน · Stamina ต่ำ = ขอบจอเต้น · ปลากิน = ทุ่นกระตุก
- **โหมดโมโน** สำหรับผู้ที่ได้ยินข้างเดียว
- **ลดเสียงกระแทก** — บีบช่วงไดนามิกและตัดยอดเสียงดัง
- **ปิดเสียงเมื่อไม่ได้อยู่หน้าจอ** เป็นค่าเริ่มต้น
- ตั้งค่าเสียงทุกอย่างต้องแก้ได้จากในเกม ไม่ต้องรีสตาร์ต

## 10. สถาปัตยกรรมเทคนิค

### 10.1 เทคโนโลยีที่แนะนำ

```
TypeScript + Vite
├── React 18          → ยูไอทั้งหมด (เมนู สารานุกรม ตลาด เควส) — ยูไอเกมนี้หนักมาก
├── PixiJS 8          → เรนเดอร์ฉากฟาร์มบน WebGL
├── Zustand           → สถานะเกม
├── Howler.js 2.2     → ระบบเสียงทั้งหมด (สายผสมเสียง, audio sprite, การกระจายเสียง)
├── Zod               → ตรวจสอบไฟล์ข้อมูล (พืช เควส สูตร)
└── IndexedDB (idb)   → เซฟเกม พร้อมระบบย้ายเวอร์ชัน
```

**เหตุผลที่ไม่ใช้ Phaser ทั้งก้อน**: เกมนี้เป็นเกมยูไอ 70% เกมฉาก 30% — React จัดการยูไอที่ซับซ้อนได้ดีกว่ามาก ส่วน Pixi รับผิดชอบแค่ตารางฟาร์มที่ต้องเรนเดอร์เร็ว

### 10.2 หลักสำคัญของสถาปัตยกรรม

**1. การจำลองต้องกำหนดผลได้ (Deterministic)**
```ts
// สุ่มด้วย seed เสมอ ห้ามใช้ Math.random() ในตรรกะเกม
const rng = mulberry32(saveSeed ^ dayNumber ^ SYSTEM_SALT.WEATHER)
```
ผลดี: ทดสอบง่าย · หาบั๊กจากเซฟได้ · ทำ replay/ตารางคะแนนได้ · รองรับ co-op ในอนาคต

**2. แยก "ข้อมูล" ออกจาก "โค้ด" ให้เด็ดขาด**
พืช เควส สูตร NPC เทคโนโลยี → อยู่ในไฟล์ข้อมูล ไม่ใช่ในตรรกะ · เพิ่มผัก 1 ชนิดต้องไม่ต้องแตะโค้ดเลย

**3. ระบบเป็นฟังก์ชันบริสุทธิ์ที่เรียงลำดับได้**
```ts
type System = (state: GameState, ctx: TickContext) => GameState

const dailyTick: System[] = [
  advanceWeather, growCrops, spreadPests, consumeWater,
  updateSoil, tickLivestock, tickProcessors, updateMarket,
  rollDailyEvents, refreshQuestBoard, checkQuestProgress,
]
```

**4. เซฟเกมต้องมีเวอร์ชันและย้ายข้อมูลได้ตั้งแต่วันแรก**
เกมแนวนี้ผู้เล่นเซฟยาวเป็นร้อยชั่วโมง — ทำเซฟพังคือจบ

### 10.3 สคีมาข้อมูลหลัก (ร่าง)

```ts
type GameState = {
  version: number
  seed: number
  clock: { year: number; season: 0|1|2|3; day: number; minute: number }
  player: { stamina: number; staminaMax: number; money: number; skills: Record<SkillId, SkillState> }
  farm: {
    plots: Record<PlotId, Plot>
    buildings: Building[]
    livestock: Animal[]
    processors: Processor[]
  }
  world: { weather: WeatherState; forecast: Weather[]; market: MarketState; events: ActiveEvent[] }
  social: Record<NpcId, { hearts: number; talkedToday: boolean; storyStage: number }>
  quests: { active: QuestInstance[]; completed: QuestId[]; boardSeed: number }
  codex: { crops: Set<CropId>; fish: Set<FishId>; recipes: Set<RecipeId>; strains: Strain[] }
  research: { points: number; unlocked: Set<TechId> }
}

type Plot = {
  soil: { n: number; p: number; k: number; ph: number; organic: number; moisture: number }
  disease: number
  history: CropId[]          // ใช้คำนวณผลของการปลูกซ้ำ
  crop: null | {
    cropId: CropId
    strain: Strain           // ยีน 6 ตัว
    plantedDay: number
    growth: number
    health: number
    pests: PestId[]
  }
}

type Strain = {
  id: string
  name: string               // ผู้เล่นตั้งเองได้
  parentIds: [string, string] | null
  genes: { yield: 1|2|3|4; speed: 1|2|3|4; resist: 1|2|3|4; hardy: 1|2|3|4; flavor: 1|2|3|4; keep: 1|2|3|4 }
}
```

4. **ภาษา** — ไทยอย่างเดียว หรือทำอังกฤษด้วยตั้งแต่แรก
5. **ความยาก** — เกม cozy ผ่อนคลาย หรือมีความท้าทายจริง (ตอนนี้ออกแบบไว้เป็นแบบที่สอง พร้อมโหมดผ่อนคลายเป็นตัวเลือก)
6. **เสียง** — ใช้ไลบรารีเสียง CC0 ฟรีทั้งหมด (เริ่มได้ทันที คุณภาพกลางๆ) · จ้างนักแต่งเพลง/ซาวด์ดีไซเนอร์ (ดีที่สุด แต่มีค่าใช้จ่าย) · หรือใช้เครื่องมือสร้างเสียง AI แล้วขัดเอง (ทางสายกลาง) — **ผมแนะนำ: CC0 ใน Phase 0–2 แล้วค่อยแทนที่ด้วยของจริงตอน Phase 3** เพราะระบบเสียงสำคัญกว่าไฟล์เสียงในช่วงแรก

## ข้อเสนอแนะจากผู้ออกแบบ

ระบบทั้ง 28 อย่างนี้ออกแบบให้ต่อกันได้จริง แต่**อย่าสร้างพร้อมกัน** — เกมแนวนี้ตายเพราะสร้างระบบเยอะแต่วงจรหลักไม่สนุกมานับไม่ถ้วน

แนะนำให้ทำ **Phase 0 ให้เสร็จก่อน** (ประมาณ 400–600 บรรทัด) แล้วนั่งเล่นเอง 20 นาที ถ้าตอนนั้นยัง "อยากปลูกอีกแปลง" แปลว่าฐานถูกแล้ว ค่อยเติมอีก 27 ระบบทับลงไปได้อย่างสบายใจ

ถ้าฐานยังไม่สนุก ระบบอีก 27 อย่างก็ช่วยไม่ได้
