# ไร่ดีมีสุข Merge — บันทึกการเปลี่ยนแนวเกม

> เปลี่ยนจาก **เกมฟาร์มซิม** เป็น **เกมรวมร่าง (merge)** ธีมฟาร์มผัก
> เอกสารออกแบบฉบับฟาร์มยังอยู่ที่ [`GAME_DESIGN.md`](./GAME_DESIGN.md) และยังใช้อ้างอิงได้

## ทำไมถึงเปลี่ยน

สองเหตุผล และทั้งคู่เป็นเหตุผลที่ดี

**1. เรื่องภาพ** — คำถามก่อนหน้าคือ "ทำให้สวยระดับ Luma Island ได้ไหม" คำตอบตรงๆ คือ
ความสวยของเกมแบบนั้นมาจาก **โมเดล 3D กับทีมศิลป์** ไม่ใช่จากเทคโนโลยีที่เบราว์เซอร์ทำไม่ได้
เกมแนวรวมร่างเลี่ยงปัญหานี้ได้ทั้งหมด เพราะความสวยของมันอยู่ที่ **ไอคอนไอเทมกับยูไอ**
ซึ่งวาดด้วยโค้ดบน Canvas ให้ถึงระดับโปรดักชันได้จริง โดยไม่ต้องจ้างทีมศิลป์ 3D

**2. เรื่องความสนุก** — วงจร 30 วินาทีของเกมรวมร่างแรงกว่าเกมฟาร์มมาก
ลากของมาชนกันแล้วได้ของใหม่ทันที ไม่ต้องรอข้ามวัน
หมวด 8.1 ของเอกสารเดิมบอกว่าเครื่องยนต์ความสนุกสี่ตัวต้องมาครบ —
เกมรวมร่างให้ **ลุ้น** กับ **เก่งขึ้น** ได้ตั้งแต่นาทีแรก ซึ่งเป็นสองตัวที่เกมฟาร์มมาช้าที่สุด

## สายไอเทม 6 สาย 25 ขั้น

```
ผัก      เมล็ดพันธุ์ → ต้นกล้า → ผักกาด → ตะกร้าผัก → ลังผัก → รถเข็นผัก
ไม้      กิ่งไม้ → ท่อนไม้ → ซุง → ไม้แปรรูป → รั้วไม้
น้ำ      หยดน้ำ → ถังน้ำ → โอ่งน้ำ → บ่อน้ำ
เหรียญ   เหรียญ → กองเหรียญ → ถุงเงิน → หีบสมบัติ      (แตะเก็บเป็นเงิน)
แปลงผัก  แปลงผัก → แปลงผักงาม → แปลงผักชั้นดี           (ตัวผลิต)
กองไม้   กองไม้ → กองไม้ใหญ่ → โรงไม้                    (ตัวผลิต)
```

**ตัวผลิตรวมร่างได้เอง** คือความลึกที่สำคัญที่สุดของแนวนี้ — ผู้เล่นต้องเลือกว่าจะ
เอาแปลงผักสามอันไปรวมเป็นอันที่ดีกว่า (เสียกำลังผลิตชั่วคราว แต่ระยะยาวคุ้มกว่า)
หรือเก็บไว้ผลิตต่อ นี่คือการตัดสินใจที่ยากจริงตามเสาหลัก P2

## กติกาคุณภาพเควสที่บังคับใช้

ตัวสร้างเควสขอเฉพาะของจากสายที่ผู้เล่น **หาได้จริงแล้ว** เท่านั้น
(มีของสายนั้นบนกระดาน หรือเคยค้นพบแล้ว)

ตอนทดสอบครั้งแรกพบว่าเกมออกเควสขอ *หยดน้ำ* ตั้งแต่เริ่มเกม ทั้งที่ยังไม่มีทางหาหยดน้ำได้เลย
ซึ่งผิดกติกาข้อ 5.4 ของเอกสารเดิมที่เขียนไว้เองว่า
"ห้ามให้เควสที่ผู้เล่นทำไม่ได้ด้วยระบบที่ยังไม่ปลดล็อก" — แก้แล้ว

และเควสส่วนใหญ่ขอของ **สูงกว่าที่ผู้เล่นทำได้อยู่หนึ่งขั้น**
ถ้าขอเท่าที่มีในมือ ผู้เล่นจะกดส่งรัวๆ โดยไม่ต้องรวมร่างเลย ซึ่งข้ามความสนุกทั้งหมดของเกม

## สิ่งที่ยกมาจากงานเดิมทั้งดุ้น

ไม่ได้เริ่มจากศูนย์ — โครงสร้างพื้นฐานทั้งหมดใช้ต่อได้เลย

- **ระบบเสียง** สังเคราะห์ด้วย Web Audio · สายผสมเสียง 6 สาย · ducking · round-robin · สุ่มพิตช์ ±4%
- **ชั้น juice** · อนุภาคหลายรูปทรง · ตัวเลขลอยมีขอบ · สั่นจอ · หยุดเวลาตอนค้นพบขั้นใหม่
- **การสุ่มแบบกำหนดผลได้** · **เซฟที่มีเวอร์ชันและย้ายข้อมูลได้**
- **ตัวรวมไฟล์เดียว** พร้อมตัวตรวจสอบว่าสไตล์กับสคริปต์ไม่หายไป
- **หลักการออกแบบความสนุก** หมวด 8 ของเอกสารเดิม ยังใช้ได้ทุกข้อ
