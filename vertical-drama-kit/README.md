# ชุดเครื่องมือทำซีรีส์แนวตั้ง (Vertical Drama Kit)

อุปกรณ์ที่ใช้: **RTX 5090 32GB** + **ChatGPT (เจนภาพไม่จำกัด)** + **MacBook M5 16GB**
เป้าหมาย: ตัวละครหน้าไม่เพี้ยน เสียงไม่เพี้ยน ปากตรงเสียง

---

## 1. แบ่งหน้าที่เครื่อง

| เครื่อง | หน้าที่ | โปรแกรม |
|---|---|---|
| **ChatGPT** | เขียนบท, ออกแบบตัวละคร, ทำ Character Sheet, เจนภาพคีย์เฟรม (ภาพแรกของทุกช็อต) | ChatGPT (GPT-image) |
| **PC 5090** | ภาพ→วิดีโอ, ทำเสียงพากย์, ลิปซิงก์, เทรน LoRA, อัปสเกล | ComfyUI, Wan 2.2, InfiniteTalk, F5-TTS-THAI, AI Toolkit |
| **MacBook M5** | ตัดต่อ, ซับไตเติล, ดนตรี, เช็กงาน, อัปโหลด | DaVinci Resolve (ฟรี) หรือ CapCut, MLX-Whisper |

> หลักการ: งานหนัก GPU ทั้งหมดอยู่บน 5090 — Mac 16GB ไม่ต้องรันโมเดลวิดีโอ

## 2. ระบบกันเพี้ยน 3 ชั้น (หัวใจของชุดนี้)

### ชั้นที่ 1 — หน้าไม่เพี้ยน
1. **Character Bible** (ไฟล์ `templates/character-bible.md`) — ล็อกหน้าตา เสื้อผ้า ทรงผม เป็นข้อความเดียวกันทุกครั้ง
2. **Character Sheet จาก ChatGPT** — ภาพเดียวมี หน้าตรง / 3/4 / ข้าง / เต็มตัว / 3 อารมณ์ บนพื้นขาว
3. **ทุกช็อตเริ่มจากภาพ (Image-to-Video) เท่านั้น** — ห้ามใช้ Text-to-Video กับตัวละครหลัก
   - เจนคีย์เฟรมใน ChatGPT โดย **แนบ Character Sheet ทุกครั้ง** + prompt จาก `templates/prompts.md`
4. **LoRA ตัวละคร (เมื่อเรื่องยาวเกิน ~10 ตอน)** — เทรนบน 5090 ด้วย AI Toolkit จากภาพ 20–40 ภาพที่ ChatGPT เจน
   - ใช้ strength ประมาณ 0.6–0.75 (เกิน 0.8 หน้าจะกระพริบ)
5. **ช็อตสั้น 3–5 วินาที** กล้องนิ่งหรือเคลื่อนช้า — หน้าเพี้ยนเพิ่มตามการเคลื่อนไหว/หันหน้ามาก

### ชั้นที่ 2 — เสียงไม่เพี้ยน
1. อัดหรือเลือก **เสียงอ้างอิง 1 ไฟล์ต่อตัวละคร** (8–12 วินาที, เสียงสะอาด, อารมณ์กลาง ๆ) เก็บใน `characters/<ชื่อ>/voice_ref.wav`
2. ใช้ **F5-TTS-THAI** (โคลนเสียงภาษาไทย) **ด้วยไฟล์อ้างอิงเดิมทุกครั้ง** + ตั้ง seed คงที่
3. เจนทีละประโยค ไม่เจนทั้งฉากยาว ๆ → ฟังแล้วเจนใหม่เฉพาะประโยคที่ผิด
4. ถ้าเสียงไทยยังไม่พอใจ: ทางเลือกเสียเงิน ElevenLabs (Voice Clone) — สม่ำเสมอกว่า

### ชั้นที่ 3 — พูดไม่เพี้ยน (ปากตรงเสียง)
- **ช็อตพูด:** ใช้ **InfiniteTalk** (ต่อยอดจาก Wan, ใส่ภาพ + ไฟล์เสียง → วิดีโอคนพูด ปากตรง หัว/ตัวขยับธรรมชาติ) รันใน ComfyUI บน 5090
- **ช็อตแอ็กชันไม่พูด:** ใช้ **Wan 2.2 I2V 14B (fp8)**
- **แก้ปากเฉพาะจุด:** LatentSync (ลิปซิงก์ทับวิดีโอที่มีอยู่)
- ใส่ซับไตเติลทุกตอน — คนดู 70%+ ดูแบบปิดเสียง ช่วยกลบจุดเพี้ยนเล็ก ๆ ได้ด้วย

## 3. ลำดับงาน 1 ตอน (1–2 นาที, ~15–25 ช็อต)

```
[ChatGPT]  บทตอน → Shot list (ช็อตละ 3–5 วิ, ระบุ พูด/ไม่พูด)
     ↓
[ChatGPT]  เจนคีย์เฟรม 9:16 ทุกช็อต (แนบ Character Sheet)  → shots/epXX/sNN.png
     ↓
[5090]     F5-TTS-THAI เจนเสียงทุกบรรทัด                → audio/epXX/sNN.wav
     ↓
[5090]     ช็อตพูด → InfiniteTalk (ภาพ+เสียง)
           ช็อตไม่พูด → Wan 2.2 I2V                     → clips/epXX/sNN.mp4
     ↓
[5090]     อัปสเกลเป็น 1080x1920 (เช่น SeedVR2 / RealESRGAN)
     ↓
[Mac]      DaVinci/CapCut: เรียงคลิป + ดนตรี + SFX + ซับ (MLX-Whisper)
     ↓
[Mac]      Export 1080x1920 30fps → TikTok / Reels / Shorts
```

ใช้ `templates/episode-shotlist.csv` เป็นตารางกลางของแต่ละตอน

## 4. ติดตั้งบน PC 5090

ดูสคริปต์ `setup/install_5090.md` (Windows หรือ Linux)
ตั้งค่าแนะนำสำหรับ 32GB:
- Wan 2.2 I2V 14B **fp8** + Lightning LoRA (4–8 step) → 480x832 หรือ 720x1280, 81 เฟรม (~5 วิ)
- เปิด `--fast` / SageAttention เพื่อความเร็ว
- เจนที่ 480p ก่อน → เลือกเทคที่ดี → ค่อยอัปสเกล (ประหยัดเวลามาก)

ประมาณการบน 5090: ช็อต 5 วิ ~1–3 นาที (มี Lightning LoRA) → 1 ตอน ~1–2 ชั่วโมงเครื่องรัน

---

## 5. ติดตั้งบน MacBook M5 16GB

- DaVinci Resolve (ฟรี) หรือ CapCut
- ซับไตเติลอัตโนมัติ: `pip install mlx-whisper` แล้ว `mlx_whisper ep01.wav --language th --output-format srt`
- ไม่ต้องลง ComfyUI บน Mac (RAM 16GB ไม่พอสำหรับ Wan 14B)
- ส่งไฟล์ระหว่างเครื่อง: โฟลเดอร์แชร์ / Syncthing
